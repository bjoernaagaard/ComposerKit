## Install

```bash
npx shadcn@latest add https://snestra.github.io/ComposerKit/r/tip.json
```

This adds `components/ui/tip.tsx`, `components/ui/popup-layer.tsx` and `components/ui/theme-value.ts`, with the theme.

## Anatomy

```tsx title="Anatomy"
import { PopupLayer } from "@/components/ui/popup-layer";
import { Tip, TipProvider } from "@/components/ui/tip";

<TipProvider>
  <PopupLayer container={mainElement}>
    <Tip label="Copy message" side="top">
      <button aria-label="Copy message" />
    </Tip>
  </PopupLayer>
</TipProvider>;
```

`PopupLayer` is optional. Without it, tips and menus mount at the end of `<body>`.

## Keyboard

The [WAI-ARIA Authoring Practices tooltip pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tooltip/) opens the tip when its control gets keyboard focus and closes it with Escape.

<SpecSection section="5. Tooltips" />

## Accessibility

The control keeps its own accessible name, so a screen reader reads the same words whether or not the tip is open. Base UI links the open tip to its control, as the [tooltip pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tooltip/) describes.

### Motion

After its delay, a tip fades in and grows from `--popup-scale` at its control over `--motion-tooltip`, and leaves the same way. A tip opened by keyboard focus is drawn in one frame. Under reduced motion it only fades.
