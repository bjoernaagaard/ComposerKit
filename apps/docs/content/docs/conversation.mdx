## Install

```bash
npx shadcn@latest add https://bjoernaagaard.github.io/ComposerKit/r/conversation.json
```

This adds `components/conversation/`, with the theme, the button, the tip and the composer.

The examples below also import sample data: options, projects and chats. To run one exactly as the Code tab shows it, add that too:

```bash title="Add the sample data"
npx shadcn@latest add https://bjoernaagaard.github.io/ComposerKit/r/sample-data.json
```

[Sample data](/sample-data) lists the files it adds and where they go.

## Anatomy

```tsx title="Anatomy"
import { ConversationView } from "@/components/conversation/conversation-view";

<ConversationView
  turns={turns}
  reply={(message, style) => blocks}
  options={options}
  projects={projects}
  layout="document"
  title="Weekend plans"
/>;
// region "Weekend plans"
//   each turn: a hidden level 4 heading, the message, its actions
//   jump to the newest message
//   the composer
```

## Accessibility

The conversation is a labelled region, one of the [WAI-ARIA Authoring Practices landmark regions](https://www.w3.org/WAI/ARIA/apg/practices/landmark-regions/). Hidden level 4 headings let screen reader users move from turn to turn.

### Motion

A message you send fades in and rises `--space-turn-enter-offset` into place over `--motion-turn-enter`. Turns that were there when the view opened stay still, and so do replies, whose text streams in. The jump to the newest message eases in over `--motion-enter` when you scroll away from the end. Under reduced motion they only fade.
