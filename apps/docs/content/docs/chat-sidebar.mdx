## Install

```bash
npx shadcn@latest add https://bjoernaagaard.github.io/ComposerKit/r/chat-sidebar.json
```

This adds `components/chat-sidebar/`, with the app shell, the menu and the tip. It also adds the rules for row actions and long titles to your CSS file.

From the npm package, import each part from its own module, and load `composerkit/styles.css` after Tailwind:

```tsx title="npm"
import { ChatSidebar } from "composerkit/components/chat-sidebar/chat-sidebar";
```

The examples below also import sample chats and projects. To run one exactly as the Code tab shows it, add those too:

```bash title="Add the sample data"
npx shadcn@latest add https://bjoernaagaard.github.io/ComposerKit/r/sample-data.json
```

## Anatomy

```tsx title="Anatomy"
<AppShellSidebar>
  <ChatSidebar                     // <nav> "Chats", data-slot="sidebar"
    conversations={chats}
    projects={projects}
    activeConversationId={id}
    archived={lastArchived}
    header={<WorkspaceMenu />}      // before the search button
    renderLink={(chat) => <Link href={`/c/${chat.id}`} />}
    onOpenConversation={open}
    onNewChat={newChat}
    onTogglePin={togglePin}
    onArchive={archive}
    onUndoArchive={undo}
    onAddProject={addProject}
    onStartProjectChat={startProjectChat}
  />
  // header: the app's header, the search button, New chat, the search field
  // list: Undo, Pinned, Projects, Recent with its filter
  //   <SidebarSection>            a group that folds away
  //     <ConversationRow />       a button or link, and <RowActions />
  //     <ProjectList />           projects, and the form that adds one
</AppShellSidebar>
```

Each part is its own module under `components/chat-sidebar/`. The app owns the chats and projects and gets a callback for each change. Inside an `AppShellSidebar` on a narrow shell, picking a chat or starting one closes the drawer and moves focus to the main region. Without an app shell, the sidebar works on its own.

## Keyboard

| Key | Where | What it does |
| --- | --- | --- |
| Tab, Shift+Tab | The sidebar | Move through the header, then each row and its actions, in order. A row's actions show while focus is inside the row. |
| Enter | A chat row | Opens the chat. On a narrow shell it also closes the drawer and moves focus to the main region. |
| Enter, Space | A row's More button | Opens the menu with Pin or Unpin, and Archive. |
| Enter | Undo, after an archive | Puts the chat back. Focus lands on Undo when a chat is archived. |
| Escape | The search field | Closes the search and clears it. |
| Escape | The new project field | Cancels the new project. |

A long title scrolls into view while the keyboard focuses its row, and fades at its end until then.

## Accessibility

The sidebar is a navigation landmark named Chats. Each group, Pinned, Projects and Recent, is a section whose heading button folds it, with `aria-expanded` and `aria-controls`. The open chat has `aria-current="page"`. Each row's buttons are named for their chat, such as "More actions for Plan a trip" and "Pin Plan a trip", and the filter button says which chats Recent shows.

With a pointer that can hover, a row's actions show on hover, while focus is inside the row and while their menu is open, and until then they don't take a click. A touch screen can't hover, so there the More button always shows, and Pin and Archive are in its menu. A tap on a row's title opens the chat and never pins it.

A long title scrolls from its start toward its end on hover, but only with a fine pointer, because a tap would leave it scrolled. With reduced motion it never moves and never wraps, so the row keeps its height: it stays on one line and ends in an ellipsis.

With `renderLink`, each row is a real link, so Cmd-click, Ctrl-click, middle-click and Copy link work. A click that asks the browser for a new tab doesn't open the chat in the current page.

## Theming

Tokens that the sidebar's files use.

`--motion-marquee-ms-per-pixel` sets how fast a long title scrolls, 14ms per pixel by default, after `--motion-marquee-delay`. These rules come with `chat-sidebar.css` and with the registry item's CSS.

<TokenTable item="chat-sidebar" />

Design directions style the sidebar through these hooks instead of its structure:

| Hook | On |
| --- | --- |
| `data-slot="sidebar"` | The sidebar |
| `data-slot="sidebar-header"`, `"new-chat"` | The header and its New chat button |
| `data-slot="sidebar-list"` | The list that scrolls |
| `data-slot="sidebar-section"`, `"sidebar-section-heading"` | Each group and its heading |
| `data-slot="conversation-row"`, with `data-density` and `data-active` | A chat row |
| `data-slot="row-button"`, with `data-active` | The button or link that opens the chat |
| `data-slot="row-title"`, with `data-overflowing`, and `"row-title-track"` | The title and the text that scrolls in it |
| `data-slot="row-details"` | The two-line row's age and project |
| `data-slot="row-actions"`, and `data-row-action` (more or pin) on each button | The row's actions |
| `data-slot="project-row"` | A project |
