The examples on the component pages import sample data, so they show something real. This item installs that data where the imports look for it, so an example you copy from a Code tab compiles as it is. It is not a component and has no API of its own.

## Install

```bash
npx shadcn@latest add https://bjoernaagaard.github.io/ComposerKit/r/sample-data.json
```
