## Install

```bash
npx shadcn@latest add https://snestra.github.io/ComposerKit/r/chat-app.json
```

This adds the page `app/chat/page.tsx` and its parts in `blocks/chat-app/`, with the [App shell](/app-shell), the [Chat sidebar](/chat-sidebar), the [Composer](/composer), the [Conversation](/conversation) and the [Sample data](/sample-data). Open `/chat` to see it.

It is starter code, so it is in the registry only, not in the npm package. Edit `blocks/chat-app/chat-app.tsx` to use your own chats, projects and replies, and replace the in-memory back and forward in `tab-history.ts` with your routes.

The sidebar's open state and width are saved in the `composerkit_shell` cookie. To paint the first frame as the last visit left it, read the cookie on the server and pass it in. Next.js 16 apps made with `create-next-app` turn on Cache Components, which needs the cookie read inside `<Suspense>`:

```tsx title="app/chat/page.tsx"
import { cookies } from "next/headers";
import { Suspense } from "react";

import { ChatApp } from "@/blocks/chat-app/chat-app";
import { readShellCookie } from "@/components/app-shell/persist";

const SavedChatApp = async () => {
  const shell = readShellCookie((await cookies()).toString());

  return <ChatApp defaultOpen={shell.open} defaultWidth={shell.width} />;
};

export default function ChatPage() {
  return (
    <div className="h-dvh">
      <Suspense>
        <SavedChatApp />
      </Suspense>
    </div>
  );
}
```

## Anatomy

```tsx title="Anatomy"
<ChatApp // blocks/chat-app/chat-app.tsx
  titleBarEnd={<ShareButton />} // the end of the title bar
  railFooter={<AccountMenu />} // the foot of the rail
/>
// <AppShellProvider>                 the open state, Cmd+B or Ctrl+B, the cookie
//   <AppShell>
//     <AppShellSkipLink />
//     <AppShellTitleBar>             back, forward, the sidebar toggle, the tabs, titleBarEnd
//     <AppShellRail>                 Home, Inbox, Schedule … and railFooter
//     <AppShellSidebar>
//       <ChatSidebar />              chats, projects, search, archive with undo
//     <AppShellSplitter />
//     <AppShellMain>                 the open tab's page:
//       <HomeView />                 home-view.tsx: <ModeToggle />, the heading, <Composer />
//       <ConversationView />         an open chat
//       <PlaceholderView />          placeholder-view.tsx: a page the app hasn't built
```

`chat-app.tsx` owns the app's state: the open tabs, each tab's back and forward history from `tab-history.ts`, the chats and projects, archive with undo, and what screen readers hear after each change. The parts it puts together are the registry items, so a fix to one of them reaches the app when you add the item again.

## Keyboard

The app uses the keys of its parts. See [App shell](/app-shell#keyboard), [Chat sidebar](/chat-sidebar#keyboard), [Composer](/composer#keyboard) and [Conversation](/conversation#keyboard).

| Key | Where | What it does |
| --- | --- | --- |
| Tab | The page | The first stop is the Skip to content link, which moves focus to the main region. |
| Cmd+B (macOS), Ctrl+B (elsewhere) | Anywhere | Shows or hides the sidebar. |
| Delete | A title bar tab | Closes the tab and its back and forward history. |
| A letter | The home view | Moves focus to the composer and types the letter there, unless focus is in a text field, an open menu or a dialog. |
| Enter, Space | The mode toggle | Picks Chat or Work. |

## Accessibility

The page has the shell's landmarks: a banner for the title bar, a navigation named Main for the rail, a complementary region named Sidebar with the Chats navigation inside, and the main region, which is also the panel of the open tab. Menus and tooltips mount inside the main region, so every part of the page sits in a landmark.

After a message is sent, a chat is archived or a chat comes back, a polite live region says what changed, such as "Sent. “Plan a trip” is now at the top of Recent."

The mode toggle is a group named Composer mode with two buttons, and the chosen one has `aria-pressed="true"`. The chosen label also turns semibold, and its thumb's edges are borders, so the choice shows in forced colors.
