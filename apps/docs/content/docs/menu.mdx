## Install

```bash
npx shadcn@latest add https://bjoernaagaard.github.io/ComposerKit/r/menu.json
```

This adds `components/ui/menu.tsx`, `components/ui/popup-layer.tsx` and `components/ui/theme-value.ts`, with the theme.

## Anatomy

```tsx title="Anatomy"
import {
  MenuContent,
  MenuInfoGroup,
  MenuItem,
  MenuRadioGroup,
  MenuRadioItem,
  MenuRoot,
  MenuSeparator,
  MenuSubmenu,
  MenuTrigger,
} from "@/components/ui/menu";

<MenuRoot>
  <MenuTrigger />
  <MenuContent label="More actions">
    <MenuInfoGroup info="Sent today at 09:41">
      <MenuItem label="Pin chat" />
    </MenuInfoGroup>
    <MenuSeparator />
    <MenuRadioGroup label="Effort" value={effort} onValueChange={setEffort}>
      <MenuRadioItem value="low" label="Low" />
    </MenuRadioGroup>
    <MenuSubmenu label="Redo with">
      <MenuItem label="Shorter" />
    </MenuSubmenu>
  </MenuContent>
</MenuRoot>;
```

## Keyboard

The menu follows the [WAI-ARIA Authoring Practices menu button pattern](https://www.w3.org/WAI/ARIA/apg/patterns/menu-button/) and the [menu pattern](https://www.w3.org/WAI/ARIA/apg/patterns/menubar/). The spec's row more menu is the closest match:

<SpecSection section="4. Menus > C. Row more menu (reply more-actions)" />

## Accessibility

The trigger is a menu button with `aria-haspopup` and `aria-expanded`. The panel is a `menu` named by `label`, items are `menuitem`, and choices are `menuitemradio` with `aria-checked`, as in the [menu pattern](https://www.w3.org/WAI/ARIA/apg/patterns/menubar/). The spec's model picker uses the same radio items:
