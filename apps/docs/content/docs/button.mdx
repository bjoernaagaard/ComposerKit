## Install

```bash
npx shadcn@latest add https://bjoernaagaard.github.io/ComposerKit/r/button.json
```

This adds `components/ui/button.tsx` and `components/ui/icon-button.tsx`, with the theme and the tip.

## Anatomy

```tsx title="Anatomy"
import { Button } from "@/components/ui/button";
import { IconButton } from "@/components/ui/icon-button";

<Button variant="default" size="default">Label</Button>

// A label from data, such as a chat title, can be any length
<Button variant="outline">
  <span className="truncate">{chat.title}</span>
</Button>

<IconButton icon={PlusIcon} kind="composer" label="Attach files" />
// renders <Tip label="Attach files"><Button aria-label="Attach files" /></Tip>
```

A button is never wider than its container. Wrap a label that comes from data in a `truncate` span, as above, so a long one ends in an ellipsis instead of running past the button. The button's accessible name is still the whole label.

## Keyboard

Buttons follow the [WAI-ARIA Authoring Practices button pattern](https://www.w3.org/WAI/ARIA/apg/patterns/button/): Tab moves focus to the button, and Enter or Space activates it. A disabled button is skipped by Tab.

<SpecSection section="3. Buttons and icon buttons > States" />

## Accessibility

An icon button's `label` is its accessible name (`aria-label`) and the text of its tip, so the tip never carries the name alone. A button with `aria-pressed` is a toggle button, as in the [button pattern](https://www.w3.org/WAI/ARIA/apg/patterns/button/).

### Motion

A press with a pointer scales the button to `--press-scale` over `--motion-press`. Only the scale moves, so hover and pressed fills still change in one frame. A press from the keyboard, and any press under reduced motion, doesn't move. Set `--press-scale: 1` to turn the press off.
