## Install

```bash
npx shadcn@latest add https://bjoernaagaard.github.io/ComposerKit/r/composer.json
```

This adds `components/composer/`, with the theme, the button, the menu and the tip.

The examples below also import sample data: options, projects and chats. To run one exactly as the Code tab shows it, add that too:

```bash title="Add the sample data"
npx shadcn@latest add https://bjoernaagaard.github.io/ComposerKit/r/sample-data.json
```

[Sample data](/sample-data) lists the files it adds and where they go.

## Anatomy

State lives in your component. `useComposerController` gives you the state and the handlers for sending, uploads and dictation; the composer only draws them.

```tsx title="Anatomy"
import { Composer } from "@/components/composer/composer";
import { initialComposer } from "@/components/composer/machine";
import { useComposerController } from "@/components/composer/use-composer-controller";

const composer = useComposerController(
  onSend,
  initialComposer(options, choices)
);

<Composer
  state={composer.state}
  dispatch={composer.dispatch}
  handlers={composer.handlers}
  mode="work"
  options={options}
  projects={projects}
/>;
// data-slot="composer"
//   data-slot="composer-surface"   the form: text field, add, model, dictate, send
//   data-slot="composer-tray"      the Work tray, inside or under the form
```

### Drop and paste files

Drop files from the desktop on the composer, or paste them into it, and they attach as if the file picker had chosen them. They go through `handlers.handleFiles`, so the 25 MB limit applies and nothing attaches while a message is sending.

As soon as a drag that carries files enters the window, every composer on the page shows "Drop files to attach" over its box. Over the composer, the box takes the drop zone's color. A file dropped anywhere else does nothing, so the browser doesn't leave the app to open it. Dragging selected text into the field, and pasting text, work as before.

Pass `acceptDrop={false}` to a composer that only shows a state, as the states above do.

## Theming

Tokens that the composer's files use.

<TokenTable item="composer" />

Design directions style a drop through these hooks:

| Hook | On |
| --- | --- |
| `data-slot="composer"`, with `data-drop-ready` while files are dragged over the window and `data-drop-target` while they are over the composer | The composer |
| `data-slot="composer-drop-overlay"` | The cover that says "Drop files to attach" |
| `--drop-zone-fill`, `var(--primary)` at 8% by default, and `--drop-zone-border`, `var(--ring)` by default, on `data-slot="composer-surface"` | The drop zone's tint and border while files are over the composer |

### Motion

A file you attach eases in over `--motion-enter`, from `--enter-scale`. When the round button changes, such as Send turning into Stop, the new icon eases in from `--icon-enter-scale`. Files and the icon the composer opens with stay still, and removing a file takes it away at once. Under reduced motion they only fade.
